# City Explorer · 城市文化探索地图

Vue 3 与 Leaflet 构建的交互式城市地图，围绕上海文化地点组织检索、收藏、主题路线与空间探索。

## 使用

```sh
npm ci
npm run serve
npm run build
```

先执行 `npm ci` 和 `npm run build`，然后可双击上一级的 `启动地图.command`，打开 http://127.0.0.1:8766 。在线底图需要网络。

## 功能

- 按名称或地址搜索，实时显示结果数量、空结果提示和筛选重置。
- 地点详情、本地持久收藏、仅看收藏，以及收藏 JSON 导出。
- 三条主题路线、可取消的路线动画、热度图层与底图切换。
- 周边地点查询、两点直线距离与预设路线折线长度。
- 响应式控制面板、带名称的地图标记和组件退出清理。

收藏存于当前浏览器 localStorage；导出的 JSON 保留地点资料与时间，不是经过坐标核验的 GeoJSON 导航数据。切换路线会取消旧动画，避免过时异步操作继续写入地图。

## 数据说明

地点资料与热度是静态样例，开放时间未实时核验。使用前应核实出行信息。原始坐标系尚未核验，因此不宣称解决 GCJ-02／WGS84 偏移。路线为预设折线，测距为直线距离，没有真实道路最短路径规划。

技术栈沿用现有工程，生产构建通过；构建仍提示浏览器兼容数据较旧及约 248 KiB 的 vendor 包体积，可在后续维护中更新依赖。作品版：2026-10。
