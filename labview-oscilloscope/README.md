# Virtual Oscilloscope and Signal Processing Simulator

Native LabVIEW source for a dual-channel virtual oscilloscope and signal-processing experiment simulator.

- Seven waveform/noise types and adjustable sampling/signal parameters.
- Waveform arithmetic and Lissajous displays.
- Butterworth and Chebyshev low-pass, high-pass, band-pass and band-stop filters.
- Time-domain and FFT displays for comparing signal processing results.

Open [Virtual_Oscilloscope.vi](Virtual_Oscilloscope.vi) in a compatible LabVIEW installation (the project was documented with LabVIEW 2020). The VI is source, not a standalone executable. Some functions may require the matching LabVIEW toolkits.

This is a simulated instrument; it does not demonstrate physical data acquisition. The VI and accompanying original project material were inspected for portfolio selection, but the VI was not executed in the current environment. A school report and identifying filenames are not redistributed.
